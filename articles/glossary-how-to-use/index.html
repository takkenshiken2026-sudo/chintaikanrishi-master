1用語集の役割

用語解説は、演習でつまずいた語の定義・主体・効果を短時間で固定するリソースです。

| リソース | 向いている場面 | 使い方 |
| --- | --- | --- |
| 用語記事 | 初見・誤答直後 | 定義→演習5問 |
| 比較表 | 類似語の混同 | 違いを3行でメモ |
| 数値早見 | 期限・割合 | 演習前の5分確認 |
| よくある誤答 | 引っかけ肢 | 誤り語を記録 |
| 分野別一覧 | 弱点分野 | 週次で3語ずつ |

用語だけ週替わりで読むと断片化するため、必ず同じ週に演習を入れてください。

2誤答から用語へ戻る手順

演習後のフローを固定すると、復習の手戻りが減ります。

| 順番 | 作業 | 時間の目安 |
| --- | --- | --- |
| 1 | 誤答語をノートに書く | 5分 |
| 2 | 用語記事で定義・主体を確認 | 10分 |
| 3 | 比較表で類語の差を見る | 5分 |
| 4 | 同テーマ演習を5問 | 15分 |
| 5 | 翌週に解き直し | 10分 |

正解した語も、根拠を一文書けない場合は用語記事を開き直してください。偶然正解と定着を区別するためです。

3静的記事とアプリ演習の往復

サイト上の用語記事（静的）と、過去問・一問一答（演習）はセットで使います。

| モード | 強み | 組み合わせ |
| --- | --- | --- |
| 用語記事 | 定義の固定 | 誤答直後 |
| 通し演習 | 時間配分 | 月2回120分 |
| 一問一答 | 弱点の短時間 | 通勤・隙間時間 |
| 分野別演習 | バランス確認 | 週末2時間 |
| 解き直し | 再発防止 | 7日後 |

一問一答の使い方は専用記事で、誤答タグだけを回す運用例を確認できます。過去問の回し方は過去問の効果的な使い方とあわせて設計してください。

43分野別の優先順

全用語を均等に読むより、演習正答率が低い分野から優先します。

| 分野 | 用語学習の入口 | 演習の接続 |
| --- | --- | --- |
| 法令・制度 | 登録・重説・監督 | 条文マップと往復 |
| 契約・実務 | 借家類型・原状回復 | 比較表を先に |
| 設備・税務・その他 | 維持保全・税務・保険 | 数値早見と接続 |
| 記録 | 分野別正答数 | 50問通しで月1回 |

科目別ハブから深掘り記事へ進み、戻りは用語→演習の順を維持すると迷いにくくなります。

5直前・当日までの使い方

直前期は新語を増やさず、再発誤答語と重要度の高い定義に絞ります。

| 時期 | 用語集の使い方 |
| --- | --- |
| 試験4週前 | 誤答上位30語だけ |
| 試験2週前 | 比較表・誤答タブのみ |
| 試験1週前 | 数値早見＋解き直し |
| 前日 | 新規は見ない、睡眠優先 |

令和8年度の試験日は11月15日（日）です。学習計画全体は学習計画の立て方、直前の行動は直前対策の記事で補完できます。

8よくある質問

用語集は毎日何語読めばよいですか？
語数より、誤答・弱点に紐づく語を週10〜15語程度深く読む方が得点に効きます。読んだ語は同週中に演習5問以上で確認し、根拠を一文で書けるかをチェックしてください。月末に再発語を集計し、翌月の優先リストへ反映する運用が安定しやすいです。
用語を先に読むべきですか、演習を先にすべきですか？
初見の論点は用語で定義を固定してから演習へ進む流れが効率的です。すでに演習で誤答した語がある場合は、誤答ログから用語を開き、直後に解き直しを入れてください。比較表・よくある誤答は、混同が続くときの短時間確認向きです。
アプリ演習だけでは足りませんか？
演習だけでは定義の抜けが残りやすく、用語だけでは四肢択一の言い換えに弱い場合があります。静的な用語記事で定義を固定し、演習で言い換えに慣れ、7日後に解き直す三層がバランス良いです。50問120分の通し演習は月2回以上入れ、時間配分も本番形式で確認してください。
