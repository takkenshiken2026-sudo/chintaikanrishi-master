賃貸不動産経営管理士試験の欠席・再受験の手続きと学習の再開

学科試験の「日程変更」は、多くの場合想定と異なります。欠席・不合格後は、試験センター要項で次回申込と受験資格を確認し、学習を数値で組み直す段階に入ります。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士協議会および試験センター要項を正本として、欠席時の確認先、再受験カレンダー、学習再開の優先順位を表で説明します。詳細な振り返り手順は再受験・不合格からの学習の組み直し方も併読してください。

この記事の要点

本記事を読むと、欠席や不合格後に要項で確認すべき手続きと、次回試験に向けた学習再開の順序が分かり、情報収集に時間を取られすぎることを防げます。

  • 要項が正本
  • 日程振替は要項で確認
  • 次回締切を先に登録
  • 誤答データから再開
  • 手続き記録を一元化

1欠席と日程変更で混同しやすい点

正本は試験センター要項です。次の整理を先に固定してください。

| 用語 | 一般的な整理 | 確認先 |
| --- | --- | --- |
| 欠席 | 当日受験しなかった | 要項・合否案内 |
| 日程変更 | 個別の日取り変更は原則不可のことが多い | 要項「試験日程」 |
| 再受験 | 次年度の申込・受験 | 翌年度要項 |
| 受験料 | 返還の有無は要項・案内 | 要項「受験料」 |
| 5問免除 | 45問受験の別枠 | 要項「受験資格」 |

  • 「別日に振替」は制度がない年度が多いため
  • 体験談の「延期できた」だけで判断せず
  • 要項原文で確認してください

2欠席直後にやる確認（48時間以内）

感情の整理と並行して、手続きと学習の事実だけをメモします。

| 順番 | 作業 | 記録 |
| --- | --- | --- |
| 1 | 要項で欠席・受験料の記載を確認 | URL・年度 |
| 2 | 次回試験の公表予定を協議会サイトで確認 | お知らせ日 |
| 3 | 申込控え・受験番号を保存 | ファイル名統一 |
| 4 | 当日の体調・交通トラブルを1行メモ | 再発防止 |
| 5 | 学習は翌週から最低ライン再開 | 誤答5問 |

問合せが必要な場合。

  • 要項記載の連絡先へ事実だけを伝え
  • 回答文はPDFまたはメールで保管してください

3再受験までのカレンダー例

次回が令和9年度になる場合も、流れは同型です（日付は要項で上書き）。

| 時期 | 手続き | 学習 |
| --- | --- | --- |
| 欠席〜1か月 | 要項・FAQ確認 | 誤答分析表の完成 |
| 要項公表後 | 資格・締切を転記 | 弱点分野+30％ |
| 申込期間 | 早めに申込完了 | 通し50問月1回 |
| 試験8週前 | 受験票・会場確認 | 通し月2回 |
| 直前2週 | 持ち物・睡眠 | 解き直しのみ |

日程・申込の確認手順の表とカレンダーを共通化すると、再受験時の手戻りが減ります。

4学習再開の優先順位

再受験では教材を増やすより、前回データから配分を直します。

| 信号 | 取る行動 |
| --- | --- |
| 1分野だけ低得点 | その分野に週+3時間 |
| 時間切れ多い | 50問通しで見切り練習 |
| 再発誤答40％超 | 7日後解き直しを固定 |
| 手続き不安 | 要項URLだけ先にメモ |

振り返りの表形式は再受験・不合格からの学習の組み直し方に沿ってください。学習計画の立て方で週次枠を再設定すると、続けやすくなります。

5不合格時との共通点

不合格の場合も、次回申込・3分野演習・要項確認の習慣は同じです。

| 項目 | 欠席 | 不合格 |
| --- | --- | --- |
| 合否 | 未受験 | 要項どおり判定 |
| 次回 | 翌年度申込 | 翌年度申込 |
| 学習 | 通し演習で現在地把握 | 誤答表から再開 |
| 統計 | 合格率は参考 | 自分の正答率が主 |

  • 令和8年度を逃した場合も
  • 協議会公式サイトで次年度要項の更新を待ち
  • 古いメモの日付を必ず年度ラベルで管理してください

6よくある質問

体調不良で欠席した場合、受験料は戻りますか？
返還の有無・条件は年度要項および試験センターの案内が正本です。SNSの事例をそのまま当てはめず、要項の「受験料」章とお知らせを確認してください。問合せする場合は、申込番号・受験地・欠席日を事実として伝え、回答文を保存してください。
試験日を別の日に変更できますか？
個別の日程変更が認められていない年度が一般的です。「振替」「延期」などの表現は、要項に明記があるかどうかで判断してください。受験できない見込みが高い場合は、早めに移動・体調・仕事の調整を見直し、欠席となる場合は次年度申込に備えて学習記録だけ継続する運用が現実的です。
欠席後、いつから勉強を再開すべきですか？
1週間以内に誤答分析または直近50問通しのどちらか一方を完了させることを推奨します。手続き確認は48時間で区切り、それ以降は週次の演習枠に戻してください。再受験の詳細な振り返り表は、再受験・不合格からの学習の組み直し方の記事を参照してください。
