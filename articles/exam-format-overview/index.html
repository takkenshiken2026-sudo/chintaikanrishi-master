5試験形式で避けたい失敗

試験形式は手順を飛ばして教材だけ増やすと、50問·120分·3分野の記録が残らず改善が遅れます。

**要項を開かずに学習開始** … 11/15試験日·9/30締切·合格基準が曖昧なまま
**3分野を同量のまま固定** … 契約·実務12/15が続いても配分を変えない
**50問通しを試験直前だけ** … 120分配分の練習が不足する
**誤答理由を記録しない** … 解き直し日が入らず再発が増える

具体例として6月14日（日）に要項5項目を1枚メモし、6月21日（日）に3分野演習15問で正答数を記録、契約·実務が12/15未満なら翌週からその分野に週+2時間振り替えると、数字で計画が動きます。

8よくある質問

50問120分で1問あたり何分使えますか？
120分÷50問で平均2分24秒（約2.4分/問）です。45問免除時は約2.7分/問になります（要項で再確認）。例えば9/7（日）50問120分通し——前半25問60分→後半25問55分→見直し5分——2分超の迷い問番号を通し後に記録し、翌週の演習時間を再配分する運用が定番です。
いつから50問通し演習を始めるべきですか？
試験8〜10週前から通し比重を上げるのが基本です。一例として6/11（木）·11/15まで残り22週なら——6/14〜8/9分野別20問、9/7（日）通し1回目、10/5（日）通し2回目、11/10（月）最終通し——序盤から毎月1回入れると時間切れの癖が早く見えます。
45問受験の場合、演習も45問に合わせますか？
申込予定の受験形態に合わせるのが基本です。例えば8/3（月）12:00申込前に50問か45問かを確定し、45問免除なら9/7（日）から45問120分通しを月2回——50問通しも月1回は用意すると問題数感覚のズレを防げます。詳細は賃貸不動産経営管理士の5問免除とはの記事と要項で確認してください。
