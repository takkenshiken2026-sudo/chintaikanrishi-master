賃貸不動産経営管理士試験の改正民法・契約不適合責任の試験対策

2020年改正民法では「瑕疵担保」から「契約不適合」へ用語が変わり、過去問の表記と教材の新旧が混在しやすい分野です。試験は50問・120分・3分野、令和8年度の試験日は2026年11月15日（日）13:00〜15:00です。本記事では試験センター要項を前提に、不適合の類型、買主・賃借人側の救済、修繕請求・解除・損害賠償の整理表と、賃貸借・管理実務への接続を説明します。要件の細部は https://www.chintaikanrishi.jp/ および関係法令・テキストで確認してください。

本記事を読むと、契約不適合の要件と効果を時系列で説明でき、旧表記の過去問も用語置換して読み解けるようになります。

  • 長文は争点メモ先行

1用語の置き換えを先に固定する

過去問・古い解説では「瑕疵」「担保」が残っているため、読む前に用語対応を書きます。

| 旧表現の例 | 読み替えの例 | 演習での注意 |
| --- | --- | --- |
| 瑕疵担保 | 契約不適合責任 | 選択肢の年代 |
| 瑕疵 | 契約不適合 | 類型の確認 |
| 修補・修繕 | 修補請求等 | 効果の順序 |
| 解除 | 契約関係の終了 | 借地借家法と混同しない |
| 記録 | 置換メモ | 解き直し時に参照 |

条文番号はテキストの最新版で照合し、設問では「誰が・いつ・何を求めているか」をメモ欄に先に書いてください。

2不適合の類型と効果

契約不適合は、種類・品質・数量などの観点で整理されます（詳細は民法・テキストで確認）。

| 観点 | 確認の焦点 | 誤答の典型 |
| --- | --- | --- |
| 存在 | 契約内容との差異 | 軽微な差異の見落とし |
| 通知 | 期間・方法 | 効果発生の前後 |
| 修補 | 請求・相当期間 | 解除との順序 |
| 減価・損害 | 範囲・要件 | 計算ではなく判断 |
| 演習 | 長文 | 争点の一行要約 |

賃貸借では借地借家法の修繕義務・原状回復と接続するため、同一事例で民法と借地借家法を往復すると理解が定着しやすくなります。

3修繕義務・原状回復との接続

契約不適合と賃貸借の修繕・原状回復は、別の根拠で並立しうる場面があります。

| 論点 | 民法（不適合）の例 | 賃貸借・実務の例 |
| --- | --- | --- |
| 発見 | 引渡し時・通知 | 入居時点検 |
| 修繕 | 修補請求 | 貸主・借主の義務 |
| 費用 | 減価・損害 | 原状回復控除 |
| 終了 | 解除 | 明渡し・更新 |
| 演習 | 根拠条文 | 条文をメモ欄に |

定期借家・普通借家の比較ができていると、終了場面の設問でも手が止まりにくくなります。

4週次ルート（横断論点）

民法系は短周期の反復が向きます。

| 曜日 | 内容 |
| --- | --- |
| 火 | 用語対応表の見直し |
| 木 | 事例1件を口頭で説明 |
| 土 | 不適合系演習10問 |
| 翌週火 | 解き直し |
| 月1回 | 50問通しで長文の時間 |

誤答を要件誤認・時系列誤認・他法混同に分類し、翌週は再発した分類だけ時間を追加してください。

5直前・他分野との接続

直前期は新しい民法テキストを増やさず、誤答上位と比較表に絞ります。

| 接続 | 例 |
| --- | --- |
| 民法→重説 | 説明内容の記載 |
| 民法→設備 | 設備不具合の帰属 |
| 直前 | 用語対応＋10問解き直し |

令和8年度は11月15日試験です。契約ハブから借地借家法・敷金の記事へ戻り、同じ物件想定で3分野を1周する復習が効率的です。

6つまずきやすいポイント

改正民法・契約不適合責任の試験対策では、「賃管受験者が診断する」「休職勧奨＝解雇」「ストレスチェック結果を個別に上司が全部見る」など、現場イメージと制度のズレが誤答の温床になります。特に敷金返還と原状回復、更新と再契約の混同は四択で頻出です。

  • 用語解説で定義を確認したうえで
  • 比較表タブの「混同しやすい組み合わせ」を読み
  • 演習問題で引っかけ肢を体験してください

数値・日程・合格基準は年度で更新されるため、学習前と申込前には賃貸不動産経営管理士試験センター（公式）の最新案内を確認してください。

8よくある質問

過去問の「瑕疵担保」はどう読み替えますか？
2020年改正後は契約不適合責任の枠組みで整理するのが基本です。選択肢や解説の年代を確認し、自分用の旧新対応表を1枚用意してから解き直すと混乱が減ります。効果（修補・解除・減価等）の順序は時系列図で固定し、設問では争点を先に一行で書いてください。
契約不適合と借地借家法の修繕は別物ですか？
根拠と要件が異なるため、同一トラブルでも「どの請求権か」を切り分けて読む必要があります。借地借家法の記事で修繕義務・原状回復を確認した週に、本記事の不適合の表を1回見直すと接続が定着しやすくなります。断定は避け、関係法令とテキストで前提を照合してください。
この記事だけで民法分野は足りますか？
契約不適合に特化した整理です。賃貸借全般は借地借家法・定期借家の記事と契約ハブで補完してください。50問120分の通し演習で長文の時間配分も本番形式で確認し、3分野のバランスを保ってください。出題範囲の正本は試験センター要項です。
