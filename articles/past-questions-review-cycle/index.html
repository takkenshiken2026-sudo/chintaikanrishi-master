賃貸不動産経営管理士試験の過去問の解き直しサイクル

解き直しは回数より、間隔と記録の型が決まっているかで効果が変わります。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では試験センター要項を正本として、初回通し後の復習間隔、3分野の優先順位、月2回の再演習日の置き方を表で説明します。日程・出題範囲は https://www.chintaikanrishi.jp/ で必ず最新要項を確認してください。

この記事の要点

本記事を読むと、過去問を何度・いつ解き直すかが明確になり、生活リズムに合わせた解き直しサイクルを自分で設計できます。

  • 初回通しで基準を取る
  • 当日・3日・7日で復習
  • 通し再演習は月2回
  • 再発率で優先分野
  • 直前は再発中心

1解き直しサイクルの土台（初回通し）

周期を決める前に、年度別の通しで基準点を取ります。

| 記録項目 | 目的 | 次の解き直しへ |
| --- | --- | --- |
| 総得点 | 全体の現在地 | 月次比較 |
| 分野別正答数 | 優先分野 | 週次配分 |
| 誤答の争点3語 | 復習対象 | 当日・7日後 |
| 2分超の問番号 | 時間・読解 | 配分調整 |
| 未解答数 | 見切り基準 | 通し再演習 |

初回結果がないまま間隔だけ決めても、何を優先復習すべきか判断できません。過去問の初回の解き方の記事と記録形式を揃えてから、本記事の間隔表に入ってください。

23段階の復習間隔（当日・3日・7日）

誤答は次の3タイミングで処理すると再発が減ります。

| タイミング | 時間 | 作業 |
| --- | --- | --- |
| 当日 | 30分 | 誤答のみ：正解理由を1文＋争点3語 |
| 3日後 | 20分 | 同問または類問5問 |
| 7日後 | 30分 | 再発の有無を記録 |
| 週末 | 60分 | 再発トップ5を選定 |

長文の解説を丸写ししないで、自分の誤った判断の型を1行で残してください。原因は知識不足・読解・時間の3分類に固定すると、翌週の対策がぶれにくくなります。

350問120分の再演習の入れ方

解き直しは短問だけで終わらせず、月2回は本番形式で再現します。

| 残り週数 | 再演習 | 記録の重点 |
| --- | --- | --- |
| 16週以上 | 月1回通し | 分野別正答数 |
| 8〜15週 | 月2回通し | 未解答・見切り数 |
| 5週以内 | 同一年度の解き直し中心 | 再発誤答のみ |
| 直前2週 | 短い一問一答＋誤答 | 睡眠優先 |

2回目以降は同じ年度をそのまま繰り返すより、誤答論点を別年度・分野別演習で補強してから通しに戻すと定着が進みます。

43分野の解き直し優先順位

毎週日曜に、再発率の高い分野から順に翌週の枠を割り当てます。

| 信号 | 判断 | 翌週のアクション |
| --- | --- | --- |
| 再発40％超が2週 | 最優先 | その分野+3時間 |
| 正答率が横ばい | 維持 | 解き直しのみ増 |
| 時間切れが増加 | 配分 | 見切り基準を紙に固定 |
| 1分野だけ高得点 | 偏り | 他分野に最低30分 |

分野別過去問の解き方の記事で分野表を更新し、本記事では間隔と通しの再演習日だけを月次で見直すと運用が軽くなります。

5直前期と停滞期のサイクル調整

忙しい週・直前週は、サイクルを縮めても「空白日」を作らない設計にします。

| 状況 | 縮めること | 守ること |
| --- | --- | --- |
| 残業週 | 新規の通し | 誤答3件の当日復習 |
| 停滞2週 | 教材追加 | 7日後解き直し1セット |
| 試験5週前 | 広い初見 | 再発誤答＋数値早見 |
| 前日 | 長時間演習 | 争点メモ・持ち物確認 |

令和8年度は11月15日試験です。点数分析の記事で週次3指標（得点・再発率・時間超過）だけ見れば、サイクルの修正が一度で済みます。

6よくある質問

同じ過去問は何回解き直せばよいですか？
回数より、7日後に再発しなければその論点は一旦卒業、再発すれば14日後に再登録、という運用が現実的です。同じ年度を何度も通しするより、誤答論点を分野別・一問一答で補強してから通しに戻す方が、形式変化にも強い定着になります。
解き直しと点数分析はどう連動しますか？
毎回の通し後に年度別・分野別の得点を記録し、再発誤答数だけを週次で比較してください。得点が横ばいでも再発が減っていればサイクルは機能しています。逆に得点だけ上がり再発が増える場合は、解き直し間隔を短くするか、用語確認を挟んでください。
解き直しサイクルとブックマーク復習の違いは？
本記事は時間軸（当日・3日・7日・通し再演習）の設計が中心です。ブックマークを使った復習は、誤答・迷い問のリスト管理と週1回の解き直しが中心です。ブックマークで対象を集め、本記事の間隔で回すと、リストが溜まりすぎずに済みます。
