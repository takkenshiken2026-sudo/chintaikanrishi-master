賃貸不動産経営管理士試験の混同しやすい用語

混同しやすい用語は、単語暗記よりペアで差分を固定すると判別精度が上がります。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、頻出ペア、15分ルーティン、比較表、演習接続、直前の上位5組を表で説明します。定義の正本は用語解説と公式テキストです。

この記事の要点

本記事を読むと、どの語と語をセットで覚えるべきかが分かり、演習の混同失点を減らす復習手順が持てます。

  • ペアで差分を固定
  • 15分×演習3問
  • 比較表は3列
  • 主体・時点・条件
  • 直前は上位5組

1頻出の混同ペア例

次は混同の報告が多いペアの例です。個人の誤答でリストを上書きしてください。

| ペア | 混同しやすい点 | 確認のコツ |
| --- | --- | --- |
| 重説／契約書面 | 交付義務・記載事項 | 時点で切り分け |
| 敷金／保証金 | 目的・返還 | 会計処理で対比 |
| 普通借家／定期借家 | 更新・終了 | 数字をカード化 |
| 原状回復／修繕 | 費用負担 | 主体・範囲を1行 |
| 管理業者／賃貸住宅管理業 | 登録・業務 | 法令の章で整理 |

自分の演習から「混同ペア10組」を作ることが最重要です。

21ペア15分のルーティン

混同ペア1組あたりの標準手順です。

| 分 | 作業 |
| --- | --- |
| 0〜5分 | 用語A・Bのページを並べて開く |
| 5〜10分 | 違いを1行（主体・時点・効果） |
| 10〜15分 | 同分野演習3問＋解説 |

週に3ペア進めれば、8週で24ペア分の対策ができます。用語集の活用法の深掘り上限（関連2語）と併用してください。

3比較表の3列

手書きの比較表は次の3列で十分です。

| 列 | 書く内容 |
| --- | --- |
| 項目 | 主体・要件・効果などの軸 |
| 語A | 短い定義 |
| 語B | 短い定義 |

演習で再び間違えた行だけ色を付け、直前2週間はその行だけ復習する運用が効きます。写真より手書きの方が、試験直前の想起練習に向いています。新しいペアを追加する前に、前週ペアを口頭で言えるか確認してください。

4読解ミスとの接続

混同失点は、読解不足とセットで出ることがあります。

| 抽出 | 確認例 | 混同との関係 |
| --- | --- | --- |
| 主体 | 貸主・借主・管理業者 | 当事者の取り違え |
| 時点 | 契約時・更新時 | 手続の混同 |
| 条件 | 書面・口頭の限定 | 例外の見落とし |

過去問の誤答原因の分析の抽出手順と表を共通化すると、用語ペアと設問文の読み落としを同じノートで処理できます。

5直前の上位5組

試験4週前以降は、新規ペアを増やさず再発ペアに絞ります。

| 残り | 混同対策 | 演習 |
| --- | --- | --- |
| 4週 | 週3ペア | 分野別維持 |
| 2週 | 上位5組のみ | 短問中心 |
| 1週 | 比較表読み返し | 新規なし |
| 前日 | 争点メモ | 睡眠優先 |

令和8年度は11月15日試験です。重要用語リストの直前30語と、混同上位5組を同期させてください。

6よくある質問

混同ペアはどこまで作ればよいですか？
最初は演習から10組で十分です。2週連続で正答できたペアはリストから外し、新たに混同したペアだけを追加する運用が負担を抑えます。他人のまとめペアは参考にし、最終的には自分の誤答データを正本にしてください。
混同しやすい用語と重要用語の押さえ方の違いは？
本記事は似た語のペア比較と15分ルーティンが中心です。重要用語の押さえ方の記事は、リストの作り方と週10語の積み上げが中心です。重要語リストで語を集め、本記事で混同ペアに分解する順がおすすめです。読解ミスが多い場合は過去問の誤答原因の分析も併用してください。
比較表はデジタルでもよいですか？
可能ですが、試験直前の想起練習は手書きの方が向くことが多いです。デジタルで作った場合も、主体・時点・効果の3軸は必ず1行で残してください。週日曜に上位5組だけを声に出して言えるか確認し、言えないペアは翌週の最優先に戻してください。
