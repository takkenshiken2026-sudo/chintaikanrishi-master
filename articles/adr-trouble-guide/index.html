ADR・紛争の試験対策｜近隣・記録・調整の初動手順

賃貸トラブル・ADR・近隣対応は、感覚的な「対応の正しさ」ではなく、事実確認→記録→説明→調整の順序が取れているかで問われます。試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士協議会および試験センター要項を前提に、近隣・騒音・ADRの整理表と、法令・契約分野への接続、演習の回し方を説明します。制度の最新情報は https://www.chintaikanrishi.jp/ の要項で確認してください。

この記事の要点

本記事を読むと、トラブル対応を手順ベースで整理でき、ADRと通常の管理対応の違いを設問文から判別して安定して答えられるようになります。

  • 事実確認→記録→説明の順
  • ADRは手続きで区別
  • 当事者を先に固定
  • 50問120分で時間管理
  • 要項で範囲を確認

1トラブル対応の骨格

試験では「誰が・いつ・何を確認したか」が先に問われ、結論の正しさだけを暗記しても得点が伸びにくいです。

| 段階 | 内容の例 | 演習でのメモ |
| --- | --- | --- |
| 事実確認 | 日時・場所・当事者 | 争点3語を先に書く |
| 記録 | 内容・対応者・次の手 | テンプレに転記 |
| 説明 | 借主・貸主・近隣 | 説明主体を固定 |
| 調整 | 規約・契約・慣行 | 根拠条文を1行 |
| ADR | 調停・紛争処理 | 通常対応と比較 |

長文設問。

  • 選択肢を読む前に時系列を紙に書くと
  • 手続きが飛んだ誤り肢を除外しやすくなり

2近隣・騒音の押さえ方

近隣トラブルは、当事者（借主・貸主・管理会社・近隣）の役割が混同されやすいテーマです（詳細はテキスト・要項で確認）。

| 論点 | 確認の焦点 | 混同注意 |
| --- | --- | --- |
| 初動 | 事実関係の把握 | 結論から入らない |
| 記録 | 日時・内容・対応 | 口頭のみで終えない場面 |
| 説明 | 借主への連絡 | 貸主・管理会社の役割 |
| 規約 | 管理規約・使用細則 | 契約条項との関係 |
| 続発 | 再発防止の措置 | 一次対応と本対応 |

管理会社が「対応した」と書かれていても、受託範囲内か貸主指示かを切り分けてから選択肢を読んでください。

3ADRの位置づけ

ADR（裁判外紛争解決）は、訴訟・調停・あっせん等と並べて「いつ・誰が・何をするか」で整理します。

| 比較 | 通常の管理対応 | ADRの場面 |
| --- | --- | --- |
| 目的 | 日常のトラブル収束 | 紛争の解決手続 |
| 主体 | 管理会社・貸主等 | 当事者・機関 |
| 記録 | 社内・契約上の記録 | 手続上の提出物 |
| 時期 | 発生直後 | 協議・調停段階 |
| 演習 | 手順の順序 | 適用・非適用の判断 |

「ADRだから必ず調停」と決めつけず、設問文の手続き段階を先に確定してください。

4記録・重説・規約の接続

トラブル記録は、重要事項説明・管理受託・原状回復と接続して出題されます。

| 接続 | 例 |
| --- | --- |
| 記録→重説 | 説明事項・交付書面 |
| 記録→契約 | 特約・禁止事項 |
| 記録→退去 | 原状回復・精算 |
| 週次 | 用語2語→演習10問→解き直し |

誤答は「記録の欠落」「説明主体の誤認」「ADR手続の混同」に分類し、1週間以内に同類の問題を解き直してください。

50問120分の通しで。

  • トラブル場面に時間をかけすぎないよう
  • 争点3語をメモ欄に先に書く習慣をつけてください

5演習と他分野への接続

契約・実務だけでなく、法令・設備と往復すると総合得点が安定します。

| 分野 | 戻り先 |
| --- | --- |
| 法令 | 重説・書面・監督 |
| 契約 | 滞納・立退・原状回復 |
| 設備 | 修繕・共用部分 |
| 直前 | 初動手順表と誤答上位 |

令和8年度は11月15日試験です。

  • 直前期は新規テーマを増やさず
  • 本記事の手順表
  • 誤答ノート
  • 50問通しの時間配分に集中してください

契約分野の入口は「契約・実務の学習導線」から辿れます。

6つまずきやすいポイント

賃貸トラブル・ADR・近隣対応の試験対策では、「賃管受験者が診断する」「休職勧奨＝解雇」「ストレスチェック結果を個別に上司が全部見る」など、現場イメージと制度のズレが誤答の温床になります。特に敷金返還と原状回復、更新と再契約の混同は四択で頻出です。

  • 用語解説で定義を確認したうえで
  • 比較表タブの「混同しやすい組み合わせ」を読み
  • 演習問題で引っかけ肢を体験してください

数値・日程・合格基準は年度で更新されるため、学習前と申込前には賃貸不動産経営管理士試験センター（公式）の最新案内を確認してください。

このサイトでのおすすめの流れ：①試験ガイドで制度の全体像 ②用語解説で重要語を章ごとに確認 ③一問一答で知識の穴を洗い出し ④演習問題一覧から分野別に四択演習 ⑤間違えた問題は復習機能に残す。

8よくある質問

トラブル対応で最初に作るべき表は？
事実確認・記録・説明・調整の四段階と、当事者（借主・貸主・管理会社・近隣）を並べた表が有効です。演習のたびに1行ずつ具体例を足し、週末演習の直前に5分見直す習慣をつけてください。ADRの行は「通常対応との違い」まで書くと、似た選択肢の比較が安定します。
ADRと通常の管理対応はどう見分けますか？
設問文で「紛争解決手続」「調停」「あっせん」などの語が中心か、日常の連絡・記録かを先に判別してください。手続きの段階を時系列に書き、飛んだステップを含む肢を除外する練習が効きます。細部はテキストと演習解説で補完し、制度変更は要項で確認してください。
この記事だけで試験対策は足りますか？
トラブル・ADRの整理記事であり、出題範囲・合格基準の正本は試験センター要項です。原状回復・滞納立退の深掘り記事と50問120分の通し演習を組み合わせてください。令和8年度の試験日は2026年11月15日（日）、最新情報は協議会公式サイトで確認してください。
