賃貸不動産経営管理士試験の賃管法令・制度の基礎の押さえ方

賃管法令・制度は実務判断に直結しやすい基幹分野で、暗記だけでは長文設問で崩れやすくなります。借地借家法で賃貸借の原則を押さえ、賃貸住宅管理業法で管理業務の規律を補う二軸が効きます。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、2軸の全体像、主体・時点の整理、頻出論点、演習の回し方、他分野接続を表で説明します。出題範囲は https://www.chintaikanrishi.jp/ の要項で必ず上書き確認してください。

この記事の要点

本記事を読むと、賃管法令・制度分野をどこから学ぶべきかが明確になり、借地借家法と賃管業法を軸に、預り金・更新・明渡を過去問で確認する進め方が分かります。

  • 借地借家法と賃管業法の2軸
  • 主体・時点を先に整理
  • 預り金・更新・明渡はセット
  • 分野別のあと横断演習
  • 週1で他分野と接続

12軸で押さえる全体像

法令・制度分野は、法律の役割分担を先に固定します。

| 軸 | 中心論点 | 演習の入口 |
| --- | --- | --- |
| 借地借家法 | 賃貸借・更新・解約 | 当事者・期間 |
| 賃管業法 | 登録・管理業務・重説 | 2条→10条台→13条台 |
| 接続 | 預り金・明渡 | 主体・手続 |
| 記録 | 争点3語 | 分類タグ |
| 確認 | 要項の章立て | 確認日 |

法令・制度の学習ハブで週次ルートを決め、本記事では2軸の目次だけを先に1枚にまとめてください。

2主体・時点・条件の整理

条文番号より「誰が・いつ・何をするか」を先に言語化します。

| 観点 | 記録例 | 誤答の典型 |
| --- | --- | --- |
| 主体 | 貸主・借主・管理業者 | 立場の取り違え |
| 時点 | 締結・更新・解約 | 通知期限の誤り |
| 条件 | 合意・法定要件 | 似た語の混同 |
| 効果 | 拒絶・解除・明渡 | 手続の飛ばし |
| 演習 | 争点3語＋分類 | 解き直し日 |

図や1枚メモで流れを描いてから演習に入ると、設問文への変換が速くなります。

3預り金・更新・明渡のセット学習

頻出論点はバラバラに暗記せず、セットで扱います。

| 論点 | 押さえる点 | 週の目安 |
| --- | --- | --- |
| 預り金 | 保全・返還・分別 | 短問8問 |
| 更新 | 拒絶・合意・通知 | 長文5問 |
| 明渡 | 手続・費用整理 | 事例5問 |
| 重説 | 説明主体・書面 | 比較1行 |
| 記録 | 再発タグ | 日曜30分 |

賃貸住宅管理業法の試験対策の記事で条文マップを作ったうえで、本節の3論点を同じ週に往復すると理解が途切れにくいです。

4演習の回し方（分野別→横断）

演習は分野別のあと、横断の解き直しを入れます。

| 段階 | 内容 | 時間 |
| --- | --- | --- |
| 1 | 借地借家法中心15問 | 45分 |
| 2 | 賃管業法・預り金15問 | 45分 |
| 3 | 更新・明渡複合10問 | 計測 |
| 4 | 誤答の解き直し | 3日・7日後 |
| 5 | 月2回50問通し | 120分 |

正答肢だけでなく誤り肢の不適切な語まで一文で説明できるまで復習すると、消去法の精度が上がります。

5他分野との接続（孤立させない）

法令・制度は契約・実務・設備分野の橋渡しになります。令和8年度は11月15日試験です。

| 接続 | 重なる論点 | 週の習慣 |
| --- | --- | --- |
| 契約・実務 | 更新・原状回復 | 関連5問 |
| 設備・税務 | 修繕・費用 | 数値カード |
| 横断 | 同一事案の多視点 | 週1回 |
| 直前8週 | 再発論点のみ | 通し月2回 |
| 記録 | 分野タグ | 表で集計 |

頻出論点の記事で優先順位を決め、本記事の2軸メモと合わせて直前期の解き直しリストを作ると効率的です。

6よくある質問

苦手分野だけ先に学べますか？
可能ですが、借地借家法と賃管業法は他分野の設問にも影響するため、全体を1周して用語と主体をそろえてから弱点へ時間を多めに配分する順が効率的です。預り金や更新・明渡だけを切り出すと、長文で論点が混在したときに崩れやすくなります。
基礎の押さえ方と法令ハブの違いは？
法令・制度の学習ハブは、用語・演習・関連記事を往復する週次ルートが中心です。本記事は、2軸の全体像と主体・時点の整理、演習段階の設計が中心です。ハブでルートを決め、本記事で2軸メモと預り金・更新・明渡のセット学習を固定する順がおすすめです。
独学でのおすすめの進め方は？
平日に条文趣旨の確認、週末に演習という役割分担が効果的です。月曜から木曜で借地借家法と賃管業法の要件整理を進め、金曜に預り金・更新・明渡の要点を見直し、土日に関連演習をまとめて解いてください。この反復で暗記から実戦判断へ移行しやすくなります。
