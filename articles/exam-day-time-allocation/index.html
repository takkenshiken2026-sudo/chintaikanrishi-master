賃貸不動産経営管理士試験当日の時間配分（50問120分）

本番の時間切れは、知識不足だけでなく「配分の型が再現できていない」ことが多いです。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、直前1〜2週間の計測演習、当日の中間チェック、見切りと見直し10分の固定ルールを表で説明します。試験時間・問題数の変更は https://www.chintaikanrishi.jp/ の要項で必ず上書き確認してください。

この記事の要点

本記事を読むと、50問120分で時間切れしにくい解答ペースの作り方と、直前1〜2週間に何を計測演習で固めるべきかを数値で管理できる手順が分かります。

  • 直前は配分の再現
  • 30分・60分で中間確認
  • 2分超は保留
  • 最終10分は見直し専用
  • 分野別の詰まりを記録

1直前1〜2週間の絞り込み

直前1〜2週間は、範囲追加より配分の再現性を上げる段階です。

| 優先 | やめること | 入れること |
| --- | --- | --- |
| 最優先 | 新規テキストの大量インプット | 50問120分の通し計測 |
| 高 | 分野の網羅 | 誤答の解き直し |
| 中 | 細かい用語追加 | 2分超の問番号記録 |
| 低 | 模試の乱発 | 月2回までの通し |
| 記録 | — | 分野別の詰まり箇所 |

時間を計った演習の記事で段階導入を決め、本記事では当日ルールが演習で守れるかだけを週2回検証してください。

2最終確認リスト（時間ルール）

持ち物リストとは別紙で、時間ルールを行動文で書きます。

| 項目 | 行動文の例 | 確認タイミング |
| --- | --- | --- |
| 開始直後 | 問題冊子を1周し易問を印す | 0〜5分 |
| 30分時点 | 12〜15問到達を確認 | 30分 |
| 2分超 | 印を付け次へ進む | 解答中 |
| 60分時点 | 25問前後を目安 | 60分 |
| 終了10分前 | 見直しのみ | 110分〜 |

試験当日の流れの記事で会場到着から着席までの時刻を固定し、本記事のルールは机上に置く1枚にまとめてください。

3当日のタイムライン（解答工程）

時刻と解答工程を対応させると、中盤の失速に気づきやすくなります。

| 時刻目安 | 工程 | 到達問数の目安 |
| --- | --- | --- |
| 0〜15分 | 易問優先で前進 | 8〜10問 |
| 15〜30分 | 保留を増やさない | 12〜15問 |
| 30〜60分 | 遅れがあれば易問へ戻る | 25問前後 |
| 60〜90分 | 保留の再挑戦 | 38〜40問 |
| 90〜110分 | 未記入の埋め | 50問まで |
| 110〜120分 | 見直し専用 | 転記・未記入 |

時間配分の戦略の記事で解答順の設計を先に決め、本記事の表は演習2回で自分の到達問数に合わせて数字だけ調整してください。

4分野別の詰まりと配分の調整

3分野で詰まり方が違うため、演習記録で偏りを見ます。

| 分野 | 詰まりやすい型 | 当日の扱い |
| --- | --- | --- |
| 法令・制度 | 条文の読み取り | 易問から取り切る |
| 契約・実務 | 長文・当事者整理 | 2分で保留 |
| 設備・税務 | 数値・条件 | 印付きで後回し |
| 全体 | 後半の未着手 | 30分チェックで修正 |
| 記録 | 2分超の問番号 | 翌週の解き直し |

直近演習で最も2分超が多い分野に、直前週の解き直し時間を+30分寄せると通し得点が安定しやすくなります。

5見直し10分の点検順

最終10分は新規解答より、未記入と転記ずれの防止が優先です。

| 順番 | 点検 | 目安時間 |
| --- | --- | --- |
| 1 | 未記入の有無 | 3分 |
| 2 | 印付きの確定 | 4分 |
| 3 | 行番号と解答欄 | 2分 |
| 4 | 保留の最終判断 | 1分 |
| 記録 | 当日の崩れ要因 | 翌日メモ |

令和8年度は11月15日試験です。

  • 直前1週は新規通しを減らし
  • 争点メモと睡眠を優先し
  • 当日は本記事の10分点検順だけを机上で再確認してください

6よくある質問

直前1週間は何問演習すればよいですか？
新規問題を増やすより、50問120分の通しを時間計測で1〜2回入れる方が効果的です。正答率より30分・60分時点の到達問数と2分超の問番号を記録し、当日ルールが守れたかを検証してください。配分表の設計は時間配分の戦略の記事と要項で確認します。
当日の時間配分と時間計測演習の違いは？
時間を計った演習の記事は、段階導入と計測記録・解き直しが中心です。本記事は、直前の絞り込みと当日の中間チェック・見直し10分の運用が中心です。先に計測演習で到達問数の目安を作り、本記事のタイムラインで当日手順に落とし込む順がおすすめです。
2分で解けない問題はどうしますか？
印を付けて先へ進み、115分以降の見直し枠で再挑戦する運用が基本です。2分超を続けると後半の未着手が増え、得点の取りこぼしにつながりやすいです。演習では2分超の問番号を毎回記録し、直前週に同型だけ解き直してください。
