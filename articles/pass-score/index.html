賃貸不動産経営管理士試験の合格点・合格率の見方（50問120分）

合格点と合格率は、学習のモチベーションより「自分の演習が基準を超えているか」を測る指標として使うのが効果的です。賃貸不動産経営管理士試験は令和8年度も50問・120分・3分野、試験日は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士協議会および試験センター要項を正本として合格基準の確認手順を表に整理し、分野別正答率の記録方法と、模試得点から逆算した週次の改善目標まで説明します。基準得点・統計の数値は年度で変わるため、学習中も https://www.chintaikanrishi.jp/ の公表資料で上書き確認してください。

この記事の要点

本記事を読むと、要項どおりの合格基準の確認方法と、自分の50問演習から「あと何問分の弱点か」を数値で把握し、3分野の時間配分を調整できるようになります。

  • 合格基準は試験センター要項が正本
  • 50問120分・3分野で記録
  • 分野別正答率を主指標に
  • 令和8年度試験日11月15日
  • 模試2回連続で基準超えを目標

1合格基準・合格率の確認先

合格基準と合格率の正本は、一般財団法人 賃貸不動産経営管理士試験センターの受験要項および公表統計です。協議会サイト https://www.chintaikanrishi.jp/ から要項・お知らせへ辿ってください。

| 確認項目 | 正本 | 学習への使い方 |
| --- | --- | --- |
| 合格基準 | 要項「合格の基準」 | 模試の目標得点を設定 |
| 試験形式 | 50問・120分・3分野（要項で再確認） | 通し演習の時間配分 |
| 45問受験 | 講習修了等の該当章 | 自分が50問制か先に確定 |
| 合格率統計 | 試験センター公表資料 | 全体傾向の参考のみ |
| 試験日 | 2026年11月15日（日）13:00〜15:00 | 残り週数の逆算 |

合格率だけを見て難易度を決めず、直近の演習正答率を主指標にすると対策がぶれにくくなります。

2合格点の意味と目標得点の置き方

合格は要項公表の総合得点が基準以上であることが条件です。公表値は年度ごとに要項で確認し、次の表は50問形式での目標設定例です（問題数は要項で再確認）。

| ライン | 正答数の目安（50問想定） | 運用 |
| --- | --- | --- |
| 要項基準 | 要項記載の合格点以上 | 最優先で安定させる |
| 安全圏 | 35問前後（70％前後） | 通し模試で2回連続達成 |
| 弱点警戒 | いずれか1分野が60％未満 | その分野に週3時間追加 |
| 時間切れ | 未解答が毎回5問以上 | 捨て問判断の練習を増やす |

  • 「全部均等に勉強」より
  • 弱点1分野に時間を寄せた方が
  • 合格ラインへの到達が早いことが多い

33分野別の正答率の記録

50問120分の演習後は、総得点に加えて3分野ごとの正答数を必ず記録します。

| 分野 | 記録する数値 | 改善の触り方 |
| --- | --- | --- |
| 法令・制度 | 正答数／出題数 | 条文マップ→演習5問 |
| 契約・実務 | 正答数／出題数 | 当事者・期限の整理表 |
| 設備・税務・その他 | 正答数／出題数 | 数値・手続の早見表 |
| 全体 | 120分での未解答数 | マークミス・読み飛ばし |

2週間ごとに同じセットを解き直し、伸びない論点は用語解説で定義から見直してください。分野の入口は各科目別ハブの記事から辿れます。

4公表統計の読み方

試験センターが公表する受験者数・合格者数は、計画の参考値に留めます。自分のノートには次の3点を並べて記録してください。

| 自分用指標 | 見るタイミング | 判断 |
| --- | --- | --- |
| 通し模試の総得点 | 月2回 | 基準得点を2回連続で超えたか |
| 3分野のバランス | 毎回 | 1分野だけ極端に低くないか |
| ケアレスミス件数 | 毎回 | 知識不足か手続きミスか |

  • 過去年度の合格率を見て安心・不安を決めず
  • 直近の演習推移で学習量を増減する方が
  • 11月15日試験に向けた調整として現実的

5学習計画への反映

演習得点が基準付近で止まるときは、新規インプットより誤答の解き直しを優先します。

| 状況 | 優先する作業 |
| --- | --- |
| 総得点が基準未満 | 誤答上位15問を条文・用語で再確認 |
| 1分野だけ低い | その分野の週次時間を+3時間 |
| 時間切れが多い | 易問から処理する順序の練習 |
| 直前1か月 | 通し模試2回＋解き直しのみ |

  • 令和8年度は受験料12
  • 000円・申込締切（WEBは9月30日23:59等）と学習を同じカレンダーで管理し
  • 手続き残りで演習が空く週を作らないことが
  • 得点維持にもつながり

6よくある質問

合格点は何点ですか？
合格点は年度ごとに試験センター受験要項の「合格の基準」で公表されます。四肢択一50問・120分が基本形式ですが、講習修了等で45問受験となる場合は要項の該当章で別途確認してください。学習では要項の基準得点をメモし、通し演習で2回連続して上回れるかを追う運用が安定しやすいです。
合格率はどの年度を見ればよいですか？
試験センターが公表する最新年度の統計を参照してください。過去3年分を見てもよいですが、自分の対策には直近の演習正答率の方が重要です。合格率は全体傾向の参考に留め、目標得点は要項の合格基準から設定してください。
独学で得点を上げるには何を優先しますか？
要項で合格基準を確認したうえで、50問120分の通し演習を月2回以上入れ、分野別正答数を記録します。正答率が低い分野に週次で時間を追加し、誤答は用語定義と条文根拠まで戻って解き直してください。直前は新規範囲より、既習論点の再演習を優先すると得点が安定しやすくなります。
