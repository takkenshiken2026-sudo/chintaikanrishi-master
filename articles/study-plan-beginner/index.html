賃貸不動産経営管理士試験の初学者向け学習計画

初学者は「何をいつまでに」より先に、試験の前提と3分野の地図を固定すると迷いが減ります。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00、受験料は12,000円（要項どおり）です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、初月の優先順位、週次の最低枠、誤答ノート、通し演習の入れ方を表で説明します。日程・出題範囲は https://www.chintaikanrishi.jp/ で必ず最新要項を確認してください。

この記事の要点

本記事を読むと、初学者が最初に迷いやすい教材選択と学習配分を整理でき、基礎固めから50問120分の演習まで段階的に進める具体的な手順が分かります。

  • 要項で前提を先に固定
  • 教材は1セットに絞る
  • 初月は3分野の地図作り
  • 誤答は4列で記録
  • 通しは月1回から

1初学者が先に固定する公式前提

学習量を決める前に、試験センター要項で年度前提を確定します。ブログの体験談だけで週次計画を作ると、申込締切や問題数の取り違えが起きやすくなります。

| 項目 | 令和8年度（要項・公式案内） | 計画への反映 |
| --- | --- | --- |
| 試験日 | 2026年11月15日（日）13:00〜15:00 | 残り週数の起点 |
| 形式 | 50問・120分・3分野 | 通し演習の条件 |
| 受験料 | 12,000円 | 申込週の学習調整 |
| 出題範囲 | 要項の科目表 | テキスト目次の照合 |
| 更新 | 公式お知らせ | 月1回15分で差分確認 |

試験概要の記事で3分野の全体像を押さえたうえで、本記事の週次表に入ると初学者でも配分がぶれにくくなります。

2教材を1セットに絞る基準

初学者は教材の追加より、同じセットの反復で定着を作る方が得点に直結しやすいです。

| 役割 | 選び方 | 避けること |
| --- | --- | --- |
| 基本書 | 3分野を通読できる1冊 | 要項未確認の範囲外 |
| 問題集 | 四肢択一・解説に根拠 | 形式が違うアプリだけ |
| 演習 | 当サイトの分野別・通し | 解きっぱなし |
| 用語 | 誤答直後5分 | 用語だけで終わる |
| 追加 | 正答率が伸びない分野のみ | 月2冊以上の購入 |

最初の30日の学習計画の記事と週次テンプレを揃えると、初月の役割分担（診断→配分）が一度で決まります。

3初月の3分野配分（週8時間の例）

週8時間の例です。可処分時間に合わせて総量は調整してください。

| 分野 | 時間 | 初月の中心 |
| --- | --- | --- |
| 法令・制度 | 3時間 | 用語＋章末確認 |
| 契約・実務 | 3時間 | 類型の読み方＋短問10問 |
| 設備・税務 | 2時間 | 数値早見＋短問5問 |
| 横断 | 週末1回 | ミニ演習15問で現在地 |

満点ではなく「3分野を同じ解像度で触れたか」を初月の成功基準にしてください。学習計画の立て方の記事で残り週数別の目安と数字を揃えると、翌月の修正が楽です。

4誤答ノートと週次レビュー

誤答ノートは次の4列で十分機能します。

| 列 | 記入例 | 使い道 |
| --- | --- | --- |
| 分野 | 契約・実務 | 翌週の+時間先 |
| 論点 | 重説の記載事項 | 用語確認 |
| 原因 | 読解・知識・時間 | 対策の種類 |
| 再確認日 | 7日後 | 解き直し |

毎週日曜に「再発誤答トップ3」を選び、翌週の平日30分枠へ優先配置してください。過去問の効果的な使い方の記事と記録形式を共通化すると、初月から復習が途切れにくくなります。

5通し演習と直前の切り替え

初学者でも、残り12週前からは50問120分の通しを月1回以上入れます。

| 残り | 演習 | 記録 |
| --- | --- | --- |
| 16週以上 | 分野別中心＋月1回通し | 分野別正答数 |
| 8〜15週 | 週末20問＋通し月2回 | 未解答数 |
| 5週以内 | 解き直し中心 | 再発誤答のみ |
| 申込期 | 手続き優先 | 誤答10問は維持 |

令和8年度は11月15日試験です。直前1か月は新規教材を増やさず、誤答上位と数値早見に時間を寄せてください。

6本番形式への移行

本番形式への移行は、学習後半で急に行うのではなく早めに準備します。50問120分の配分を試すことで、問題の取捨選択と見直し手順が明確になります。通し演習では、迷った問題に使った時間を記録し、次回の見切り基準を設定してください。初学者は知識不足より時間配分で失点するケースが多いため、本番形式の訓練を継続的に入れることが安定得点への近道です。

7直前期の絞り込み

直前期は『新しいことを増やす』より『解ける問題を確実に取る』方針で進めます。過去の誤答記録から再発率の高い論点を抽出し、優先順に解き直してください。

  • 公式情報の更新確認
  • 試験当日の持ち物確認
  • 会場アクセス確認も同時に行い

精神的な不安を減らすには、直前の学習内容を固定して迷いを減らすことが有効です。最後は復習範囲を絞り、再現性のある手順を維持してください。

8よくある質問

初学者は何週間前から始めればよいですか？
試験日の20週前からでも、8週前からでも構いません。重要なのは残り週数で週次の最低枠を決め、毎週同じ型で回すことです。開始が遅い場合は初月を短くし、8週前から通し50問120分の比重を上げてください。試験日・申込締切は要項で必ず再確認してください。
1分野だけ先に進めてもよいですか？
2週間程度の集中は有効な場面もありますが、長期間それだけだと他分野が劣化しやすくなります。賃貸不動産経営管理士試験は総合点勝負なので、3分野に最低の接触枠を残し、追加時間だけを苦手分野へ当てる二段階配分が安定しやすいです。
初学者向け計画と学習計画の立て方の違いは？
本記事は初学者の初月・教材選定・週次最低枠が中心です。学習計画の立て方の記事は、残り週数別の全体設計と申込・試験日との同期が中心です。先に本記事で初月を終え、翌月から全体設計の表で週合計だけ調整する順がおすすめです。
