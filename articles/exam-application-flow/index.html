賃貸不動産経営管理士試験の申込みの流れ（WEB・郵送）

申込みは「資格確認→方法選択→情報入力→受験料→完了確認→受験票」の順で進めると漏れが減ります。令和8年度は50問・120分・3分野、試験日2026年11月15日（日）、受験料12,000円です。本記事では一般財団法人 賃貸不動産経営管理士協議会および試験センター要項を正本として、WEB申込と郵送申込のフロー差、写真・受験地の準備、不備連絡への対応までを表で説明します。締切は方法ごとに異なるため、申込前に https://www.chintaikanrishi.jp/ の最新要項を開いてください。

この記事の要点

本記事を読むと、WEBまたは郵送で申し込むときの手順とチェックポイントが分かり、入力ミス・写真不備・決済エラーを防いで受験票確認まで進められます。

  • 資格確認が最初のステップ
  • WEBは9月30日23:59まで（公表例）
  • 郵送は9月24日消印・願書請求期限あり
  • 受験料12,000円
  • 受験票で会場・時刻を確定

1申込の全体フロー

申込の正本は試験センター令和8年度受験要項です。下表は手順の骨格で、細部は要項の「申込方法」を必ず読み直してください。

| 段階 | 作業 | 正本 |
| --- | --- | --- |
| 1 | 受験資格の確認 | 要項「受験資格」 |
| 2 | WEB／郵送の選択 | 要項「申込方法」 |
| 3 | 写真・本人情報の準備 | 要項の写真規格 |
| 4 | 受験地の選択 | 要項の会場案内 |
| 5 | 受験料12,000円の支払 | 要項「受験料」 |
| 6 | 完了確認・受験票 | 要項・公式案内 |

試験日は2026年11月15日（日）13:00〜15:00（50問・120分）です。申込が済んだら、残り週数から3分野の学習枠をカレンダーに書き込んでください。

2WEB申込の流れ

令和8年度WEB申込の受付は、2026年8月3日（月）12:00〜9月30日（水）23:59が公表例です。

| ステップ | 内容 | つまずき防止 |
| --- | --- | --- |
| 事前 | 顔写真データを規格どおり作成 | 締切直前の再撮影を避ける |
| 入力 | 氏名・生年月日・受験地 | 身分証と1文字ずつ照合 |
| 決済 | 受験料12,000円 | カード限度・名義を確認 |
| 完了 | 確認画面・メール控え保存 | 未完了のまま閉じない |
| 後日 | 受験票の表示・印刷 | 会場名・開始時刻を転記 |

締切当日はアクセス集中が想定されるため、9月中旬までに決済完了を目標にすると安全です。

3郵送申込の流れ

郵送申込は締切が早く、願書請求の期限も別途あります（令和8年度は9月14日12:00まで等）。

| ステップ | 内容 | 期限の目安（要項で確認） |
| --- | --- | --- |
| 願書請求 | 要項どおりの方法で請求 | 9月14日12:00まで（公表例） |
| 記入 | 申込書へ正確に記入 | 消し込み不可の欄に注意 |
| 写真貼付 | 要項サイズの写真 | 規格外は不備になりやすい |
| 振込 | 受験料12,000円 | 払込用紙・振込期限を要項で確認 |
| 発送 | 9月24日（木）消印有効（公表例） | 局の混雑を避け早めに |

WEBの9月30日締切と混同しないよう、郵送用のカレンダーを別に用意してください。

4写真・受験地・本人情報のチェック

不備連絡の多くは、写真規格と氏名表記の不一致です。

| 項目 | WEB | 郵送 |
| --- | --- | --- |
| 写真 | データアップロード | 申込書へ貼付 |
| 氏名 | 身分証と完全一致 | 筆記体・旧字体に注意 |
| 受験地 | 要項の選択肢から | 会場は受験票で確定 |
| 連絡先 | メール・電話を要項どおり | 不備通知の届き先を確認 |

申込完了後。

  • 受験料の控えと申込内容のスクリーンショット（または申込書控え）を同じフォルダに保存し
  • 受験票到着時に照合してください

5申込後〜試験日まで

受験票が届いたら、次の4点を11月15日までに固定します。

| 確認項目 | 具体的な見方 |
| --- | --- |
| 会場 | 正式名称・住所・最寄り駅 |
| 開始時刻 | 13:00開始、12:30頃到会目安 |
| 持ち物 | HB鉛筆・消しゴム・受験票・身分証（要項追記に従う） |
| 学習 | 50問120分の通し演習を月2回 |

不備連絡があった場合は、要項記載の期限内に修正してください。日程の一覧は「日程・申込の確認手順」、受験料の詳細は「受験料と支払い」の記事で補完できます。

6よくある質問

WEB申込と郵送申込はどちらがよいですか？
どちらも要項どおりの正式手続きです。PC操作に慣れている方はWEB、紙の記録を残したい方は郵送が向きやすいです。郵送は締切が早い（令和8年度は9月24日消印有効の公表例）ため、方法を決めたら締切を別カレンダーに登録してください。
申込みに必要な写真の規格はどこで確認しますか？
試験センター受験要項の写真・申込書の章が正本です。WEBはデータファイルのサイズ・背景、郵送は貼付サイズが異なるため、選んだ方法の記載だけを読んでください。規格外は不備となりやすいので、申込開始週に写真を用意し、締切直前の再撮影を避けてください。
申込完了後に何を確認すればよいですか？
決済・振込の控え、申込内容の確認画面または申込書控えを保存してください。受験票で会場・氏名・開始時刻を身分証と照合し、持ち物リストを前日チェック用に転記します。令和8年度の試験日は11月15日（日）13:00〜15:00、50問120分です。最新案内は要項と公式サイトで再確認してください。
