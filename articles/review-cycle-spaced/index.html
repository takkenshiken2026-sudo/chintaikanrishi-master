賃貸不動産経営管理士試験の間隔を空けた復習

同日に何度も解く反復だけでは、本番で思い出せない知識が残りやすいです。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、最小サイクル、誤答分類、3分野の再ミス管理、偶然正解、直前の切り替えを表で説明します。出題範囲の改定は https://www.chintaikanrishi.jp/ の要項で必ず上書き確認してください。

この記事の要点

本記事を読むと、復習日をカレンダーに固定し、忘却を抑えながら50問120分に耐える定着力を作る手順が分かります。

  • 3・7・14日を先に予約
  • 誤答は4タグで分類
  • 偶然正解も再挑戦
  • 3分野で再ミス集計
  • 直前はリスト縮小

1最小サイクル（3・7・14日）

間隔反復は、再挑戦日を先に書くことから始まります。

| タイミング | 目的 | 合格基準 |
| --- | --- | --- |
| 直後 | 争点3語を記録 | 分類タグ |
| 3日後 | 短期記憶の確認 | 根拠1行 |
| 7日後 | 再発の有無 | 同型5問 |
| 14日後 | 定着判定 | 説明1分以内 |
| 卒業 | 2回連続説明可 | リストから除外 |

間違いノートの作り方の記事で記録列を先に決めると、本記事の日付運用だけを週次で回せます。

2誤答分類と処方

分類が曖昧だと、同じ失点を別原因と誤認します。

| タグ | 信号 | 次の一手 |
| --- | --- | --- |
| 知識不足 | 定義が言えない | 用語・条文 |
| 読み違い | 条件の見落とし | 主体・時点・条件 |
| 時間不足 | 未着手・後半崩れ | 解答順 |
| 判断迷い | 二択で停滞 | 根拠語句 |
| 記録 | 再挑戦日 | カレンダー |

週末にタグ件数を集計し、最多タグへ翌週の平日枠を先に予約すると改善が速くなります。

33分野の再ミス管理

分野ごとに再ミス件数を見ると、配分の根拠がはっきりします。

| 分野 | 週次の記録 | 配分の目安 |
| --- | --- | --- |
| 法令・制度 | 再ミス数 | 多い分野+2時間 |
| 契約・実務 | 再ミス数 | 同上 |
| 設備・税務 | 再ミス数 | 同上 |
| 横断 | 時間切れ | 通し月2回 |

  • 1分野だけに閉じると総合点が伸びにくいため
  • 週次では最低1回
  • 3分野を触れるミニ再挑戦を残してください

4偶然正解と改定確認

正答でも根拠が曖昧な問題は、間隔反復の対象に含めます。

| 状態 | 扱い | 再挑戦 |
| --- | --- | --- |
| 偶然正解 | 誤答と同列 | 3・7日 |
| 改定章 | 要項確認後 | 頻度↑ |
| 範囲外の旧問 | リストから削除 | なし |
| 説明可2回 | 卒業 | 除外 |

去年の反復リストをそのまま使うと、現行範囲外の問題に時間を使いがちです。月1回要項で差分確認してください。

5直前8週の反復縮小

試験8週前は、新規論点より再発リストを優先します。

| 残り | 反復対象 | 演習 |
| --- | --- | --- |
| 8週 | 再発トップ30 | 通し月2回 |
| 4週 | 15項目 | 解き直し |
| 2週 | 争点メモ | 短時間確認 |
| 前週 | 新規なし | 睡眠優先 |

令和8年度は11月15日試験です。直前1か月は間隔を詰めすぎず、通し演習後にリストだけ更新してください。

6よくある質問

何度復習すればよいですか？
目安は直後の記録、3日後、7日後、14日後の4回です。同じタグで再ミスが続く項目だけ追加で回し、説明できる項目は卒業させてください。回数をこなすより、毎回根拠を1行で言えるかを確認する方が、50問120分での再現性に直結します。
間隔反復と間違いノートは別物ですか？
間違いノートは記録の器、本記事は再挑戦日の設計が中心です。先にノートの列（日付・分野・タグ・再挑戦日）を決め、本記事の3・7・14日をカレンダーへ書き込む順が効率的です。両方を揃えると、独学でも再発率を数字で追えます。
独学でも間隔反復はできますか？
はい。紙でもデジタルでも、再挑戦日とタグが一元管理できれば十分です。週末30分で再ミスだけを解き、2週間ごとに3分野の件数で翌週配分を更新してください。学習計画の立て方の記事と週次枠を揃えると、反復が他の演習とぶつかりにくくなります。
