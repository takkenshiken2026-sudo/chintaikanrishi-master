賃貸不動産経営管理士試験の設備・税務・その他の基礎の押さえ方

設備・税務・その他は、用語暗記より「何を判断する分野か」の地図が先です。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、5分類の学習順、分野別10問、週末横断セットを表で説明します。出題範囲の改定は https://www.chintaikanrishi.jp/ の要項で必ず上書き確認してください。

この記事の要点

本記事を読むと、設備・税務・その他をどの順で学べばよいかが分かり、建物設備から修繕・税務・保険・管理費用まで過去問で確認する道筋が具体化します。

  • 5分類で地図を作る
  • 設備から順に学ぶ
  • 用語は場面付き
  • 10問と横断を交互
  • 契約・実務と月2回接続

1設備・税務・その他の5分類マップ

基礎対策は、次の5分類で地図を作ります。

| 分類 | 判断の中心 | 最初の1週 |
| --- | --- | --- |
| 建物設備 | 名称・機能・不具合 | 用語10個 |
| 修繕 | 要否・負担 | 事例2問 |
| 税務 | 収益・経費の区分 | 比較表 |
| 火災保険 | 補償・免責 | 主体表 |
| 管理費用 | 内訳・負担 | 10問演習 |

科目構成と配点で3分野の比重を確認し、本記事の順序は自分の弱点に合わせて入れ替えても構いません。

2推奨の学習順（初めての人向け）

初回は、設備→修繕→管理費用→税務→保険の流れが読みやすいです。

| 順 | 分類 | つながり |
| --- | --- | --- |
| 1 | 建物設備 | 名称の土台 |
| 2 | 修繕 | 設備と費用 |
| 3 | 管理費用 | 内訳判断 |
| 4 | 税務 | 計上の枠 |
| 5 | 火災保険 | 事故時の補償 |
| 週末 | 横断10問 | 混同確認 |

契約・実務の原状回復を先に学んでいる場合は、修繕・管理費用を前にずらしても整合しやすくなります。

3用語カード（定義＋実務場面）

各分類5語で、定義と「どの場面で使うか」を1行ずつ書きます。

| 分類 | カードの列 | 更新 |
| --- | --- | --- |
| 設備 | 名称／機能／不具合例 | 週1 |
| 修繕 | 要否／負担／記録 | 誤答時 |
| 税務 | 対象／区分 | 月1 |
| 保険 | 補償／免責／主体 | 事例後 |
| 管理費用 | 内訳／誰が負担 | 10問後 |

  • 用語だけ暗記すると
  • 設問の場面設定で迷いやすいため
  • 必ず実務場面の1行を添えてください

4分類別10問→横断セット

過去問は、分類別と横断を交互に回します。

| 週 | 演習 | 記録 |
| --- | --- | --- |
| 奇数週 | 分類10問×1 | 主論点タグ |
| 偶数週 | 5分類横断10問 | 混同タグ |
| 誤答 | 費目・主体・条件 | 翌週再挑戦 |
| 月1 | 通しの一部 | 時間 |
| 直前 | 誤答分類のみ | 新規停止 |

過去問の効果的な使い方の記録形式に合わせると、他分野のノートと見比べやすくなります。

5契約・実務との接続

設備・税務・その他は、契約・実務の判断材料にもなります。令和8年度は11月15日試験です。

| 本分野 | 契約・実務側 | 週次 |
| --- | --- | --- |
| 修繕費 | 原状回復 | 比較1回 |
| 保険 | 事故・説明 | 事例1問 |
| 管理費用 | 委託・収支 | 争点メモ |
| 税務 | 収益認識 | 短問 |
| 横断 | 混在5問 | 月2回まで |

接続演習は月2回までに抑え、基礎の5分類が未完成のうちは横断を増やさない方が定着しやすいです。

6よくある質問

設備・税務は苦手な分野だけ先に学べますか？
苦手先行は有効ですが、5分類のつながりが強いため一部だけに偏ると費目混同が起きやすくなります。全体を1周薄く確認してから、誤答の多い分類へ時間を寄せる順が安全です。修繕と管理費用は負担主体を先に見る習慣を付けてください。
基礎と頻出論点記事（次に読む記事）の違いは？
本記事は学習順序と5分類の地図が中心です。頻出論点の記事は出題の多いタグへの週次配分が中心です。地図と10問サイクルが回るようになってから、頻出記事で優先タグを絞る流れが効率的です。基礎が未完成の段階で頻出だけ増やすと、費目混同が再発しやすい点に注意してください。
独学で5分類を続けるコツは？
平日は用語カード15分、週末は分類別10問または横断10問を固定してください。誤答理由を費目・主体・条件のいずれかでタグ付けし、翌週最初に再挑戦する習慣を崩さないでください。月1回は50問通しの一部で時間感覚も確認するとよいです。
