賃貸不動産経営管理士試験の受験地・会場の選び方と確認手順

受験地は申込時に都道府県（都市）単位で選び、会場の正式名称は受験票で確定します。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、受験地の比較軸、申込前チェック、受験票公開後の会場確認と当日移動の表を説明します。試験都市の一覧は年度で変わるため、https://www.chintaikanrishi.jp/ の要項で必ず再確認してください。

この記事の要点

本記事を読むと、生活圏と移動負担のバランスで受験地を決め、受験票到着後に会場・開始時刻・持ち物を漏れなく確認できる手順が分かります。

  • 受験地は要項が正本
  • 会場は受験票で確定
  • 移動・宿泊を先に見積
  • 氏名は身分証と一致
  • 前日までにルート確認

1申込前に比較する受験地の軸

受験地の正本は試験センター要項の「試験会場」または「受験地」です。SNSの体験談だけで決めると、会場割当や交通の想定違いが起きやすくなります。

| 比較軸 | 確認方法 | メモ例 |
| --- | --- | --- |
| 移動時間 | 自宅・職場から最寄り駅まで | 片道○時間 |
| 交通費 | 往復＋特急の有無 | ○円 |
| 宿泊 | 前泊が必要か | 要/不要 |
| 体調 | 長距離移動の負担 | 前泊推奨 |
| 当日余裕 | 13:00開始前の到着 | 12:30到会目安 |

候補は2〜3都市に絞り、申込画面の選択肢と要項の表記が一致するか確認してから決めてください。

2申込時の入力とよくある不備

オンライン申込では受験地（都市）を選択し、会場は後日割当されます。

| 項目 | 注意 | 不備の例 |
| --- | --- | --- |
| 氏名 | 身分証と完全一致 | 旧姓・スペース |
| 生年月日 | 西暦/和暦の誤入力 | 1日ずれ |
| 受験地 | 要項の選択肢のみ | 存在しない都市 |
| 写真 | 規格・背景（要項） | サイズ不一致 |
| 受験料 | 12,000円・決済完了 | 未決済のまま終了 |

申込みの流れの記事でWEB・郵送の手順全体を把握し、本記事の表で受験地と本人情報を消し込んでください。

3受験票で確定する会場情報

会場名・住所・開始時刻は受験票が正です。申込時の都市と異なる会場が割当される場合があります。

| 確認項目 | 具体的な見方 |
| --- | --- |
| 会場正式名称 | 地図アプリで住所検索 |
| 開始時刻 | 13:00開始（要項・受験票） |
| 受付・開場 | 要項・受験票の記載 |
| 氏名表記 | 身分証と1文字ずつ照合 |
| 受験番号 | 控えと一致 |

初めての会場は試験2週間前に最寄り駅から徒歩ルートを確認し、工事中・改札変更がないか地図の最新情報も見ておくと安心です。

4遠方受験の移動・宿泊計画

遠方の場合は、試験日だけでなく前日の体調管理まで含めて計画します。

| プラン | 向き | 注意 |
| --- | --- | --- |
| 当日朝移動 | 2時間以内 | 遅延リスクを織り込む |
| 前泊 | 3時間超・早朝発 | 宿泊先は会場近く |
| 会社休暇 | 半休・全日 | 申込前に仮押さえ |
| 交通手段 | 新幹線・飛行機 | 変更規則を確認 |

令和8年度は11月15日（日）実施です。帰路の最終便時刻も先に調べ、試験後に焦らないようカレンダーに書いておきます。

5当日までのチェックリスト

受験票確認後、次のリストを前日までに完了させてください。

| # | 項目 | 状態 |
| --- | --- | --- |
| 1 | 会場住所・最寄り駅 | □ |
| 2 | 12:30頃到会の出発時刻 | □ |
| 3 | HB鉛筆・消しゴム・受験票・身分証 | □ |
| 4 | スマホ・参考書は持ち込まない | □ |
| 5 | 遅延時の連絡先（要項） | □ |

持ち物の詳細は試験当日の持ち物の記事、日程の全体は日程・申込の確認手順と併用すると当日の迷いが減ります。

6よくある質問

申込後に受験地や会場を変更できますか？
変更可否・手続きは年度要項および試験センターの案内が正本です。原則として申込内容の変更は限定的なことが多いため、申込前に候補都市を十分比較してください。不明点は要項記載の問合せ先へ、受験票の表記と申込控えを添えて確認するのが安全です。
会場名が申込時に選んだ都市と違う場合はどうしますか？
割当会場が正です。受験票の住所・最寄り駅で移動計画を組み直してください。遠方になった場合は宿泊や交通の手配を早めに変更し、試験前日の睡眠時間を確保してください。開始時刻13:00は変わらないため、到新着時刻だけを再計算します。
会場確認はいつまでに済ませるべきですか？
受験票が閲覧可能になったら当日中に会場・氏名・時刻を転記し、試験2週間前までにルート確認を完了することを推奨します。直前週は学習の解き直しに集中し、会場まわりの判断は前週までに終えておくと安定します。最新の開場・受付手順は要項と受験票で再確認してください。
