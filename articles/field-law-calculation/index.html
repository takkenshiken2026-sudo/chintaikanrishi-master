賃貸不動産経営管理士試験の賃管法令・制度の計算・数値問題

賃管法令・制度の数値問題は、算術より法律上の時点と主体の把握が中心です。起算日・満了日・通知の効力を図で固定しないと、似た期間表現で再発誤答しやすくなります。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、用語の区別、時系列メモ、10問セットの反復手順を表で説明します。数値・期限の改正は https://www.chintaikanrishi.jp/ の要項で必ず確認してください。

この記事の要点

本記事を読むと、賃管法令・制度の期限・数値設問を時系列で処理する手順が分かり、借地借家法と賃管業法の期間表現の違いを取り違えにくくなります。

  • 4語を先に区別

  • 10問セットを週反復
  • 通しで未解答を記録

1数値問題の前提（4語の区別）

計算論点の前に、似た語を切り分けます。

| 語 | 意味の焦点 | 誤りやすい点 |
| --- | --- | --- |
| 期限 | 行為の締切 | 期間と混同 |
| 期間 | 継続する長さ | 起算日の読み違い |
| 通知時点 | 効力発生 | 到達・提出の混同 |
| 返還時点 | 預り金の処理 | 管理責任の主体 |
| 記録 | 図1枚 | 演習ごと更新 |

数字だけ暗記すると設問の背景を誤解しやすいため、各語を「誰が・いつ・何をするか」に結び付けてから演習へ進んでください。

2借地借家法と賃管業法の並列表

同じ「○日」でも条文趣旨が異なるため、並べて比較します。

| 場面 | 借地借家法 | 賃管業法・実務 |
| --- | --- | --- |
| 更新・終了 | 期間・通知 | 手続の段階 |
| 書面・説明 | 契約前後 | 交付・記載 |
| 預り金 | 返還条件 | 分別・管理 |
| 明渡 | 猶予・手続 | 費用整理 |
| 演習 | 交互に5問 | 混同チェック |

借地借家法の試験対策記事で更新・立退の時系列を先に固め、本表は計算論点の照合用として演習直前に5分だけ見直す運用が効率的です。

3解答前の時系列メモ（3行）

解答前に次の3行を書く手順を固定します。

| 行 | 記入内容 | 例 |
| --- | --- | --- |
| 1 | 起算点 | 通知到達日 |
| 2 | 満了・期限 | ○日後 |
| 3 | 主体 | 貸主・借主・管理業者 |
| チェック | 単位 | 日・月・年 |
| 記録 | 2分超 | 問番号 |

問題文の日付語・期間語に下線を引き、メモが書けない問は2分で保留するルールとセットにすると時間切れが減ります。

410問セットの反復（計算特化）

計算・数値は10問×高頻度が向いています。

| 週 | 作業 | 記録 |
| --- | --- | --- |
| 月〜金 | 2問×5日 | 起算点の型 |
| 土 | 同10問再演習 | 正答数 |
| 翌週 | 誤答のみ数値隠し | 根拠説明 |
| 月次 | 預り金・更新を入替 | 再発率 |
| 通し | 50問中の数値 | 未解答 |

借地借家法と賃管業法の問題を交互に並べると、同じ日数表示でも要件の違いを見分ける訓練になります。

53分野・直前の切り替え

数値の詰まりは通し演習で検証します。令和8年度は11月15日試験です。

| 時期 | 賃管法令・制度 | 全体 |
| --- | --- | --- |
| 通常 | 10問セット週1 | 3分野バランス |
| 直前12週 | 誤答数値のみ | 通し月2回 |
| 直前4週 | 争点メモ | 新規なし |
| 当日 | 単位・転記 | 見直し10分 |
| 改定 | 要項で章確認 | 差分のみ更新 |

契約・実務分野の家賃・精算設問とも接続するため、週1回は他分野の数値1問を同じ3行メモで解くと再発が減ります。

6よくある質問

計算が苦手なら先に集中してよいですか？
計算論点の先行は有効です。ただし借地借家法・賃管業法の基本語句を軽く確認してから入ると、起算点の読み違いが減ります。平日10分の短演習を積み上げ、週末に10問セットを同条件で再計測してください。数値暗記より、誤答の型（主体・時点・単位）を記録する方が再現性が高くなります。
計算記事と頻出記事の使い分けは？
頻出論点は骨格とタグの優先順位が中心です。本記事は期限・数値の処理手順と10問セットが中心です。頻出で柱を固定したあと、数値で落とす論点だけ本記事の手順を当てはめる順が効率的です。両方の表を同じノートに貼ると、週次レビューが1枚で済みます。
ケアレスミスを減らすには？
単位と起算点の読み飛ばしが多いため、解答前の3行メモを必須にしてください。誤答した数値問題は、数値を隠して根拠だけ再現する解き直しが有効です。50問120分の通しでは2分超の問番号を記録し、翌週はその型だけ10問セットに追加する運用で着実に改善できます。
