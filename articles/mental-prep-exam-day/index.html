賃貸不動産経営管理士試験当日のメンタル対策（50問120分）

当日の不安は、知識量より「判断の迷いが続くこと」で増幅しやすいです。賃貸不動産経営管理士試験は50問・120分・3分野、令和8年度は2026年11月15日（日）13:00〜15:00です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、直前の判断訓練、当日朝の行動固定、本番中の立て直し手順、切り替えフレーズを表で説明します。会場・受験上の注意は https://www.chintaikanrishi.jp/ の要項と受験票で必ず確認してください。

本記事を読むと、当日に焦りや不安が出たときの具体的な戻し方と、解答順序と時間管理を保ちながら実力を出し切るための準備手順が分かります。

  • 直前は判断の固定
  • 朝の行動を時系列化
  • 2分で保留を再現
  • 立て直しは4ステップ
  • 切り替えフレーズを1つ

1直前1〜2週間の判断訓練

直前は暗記量より、迷ったときの動きを固定します。

| 訓練 | 記録 | 合格基準 |
| --- | --- | --- |
| 2分で保留 | 問番号 | 演習で再現 |
| 解答順 | 易→難→保留 | 3回連続 |
| 30分チェック | 到達問数 | 目標±2問 |
| 立て直し | 焦りの問番号 | 手順1行 |
| 睡眠 | 就寝時刻 | 前日と同じ |

試験当日の時間配分の記事で中間目標を先に決め、本記事では「保留に進める」判断だけを週3回の通しで練習してください。

2最終確認リスト（思考の型）

持ち物とは別に、思考の型を短い行動文で書きます。

| 場面 | 行動文 | 使うタイミング |
| --- | --- | --- |
| 開始直後 | 全体を見て易問から | 0〜5分 |
| 迷った | 印を付けて次へ | 2分経過 |
| 焦った | 深呼吸して順番を読む | 任意 |
| 後半 | 未記入を先に埋める | 90分以降 |
| 終盤 | 見直し順に点検 | 最後10分 |

試験当日の流れで到着・着席の時刻を固定し、本リストは受験票と一緒にカバンへ入れてください。

3当日朝の行動を固定する

朝の選択肢を減らすと、会場到着後の集中が保ちやすくなります。

| 時刻目安 | 行動 | 避けること |
| --- | --- | --- |
| 起床 | 前日と同じ時刻 | 寝不足の挽回 |
| 朝食 | いつも通りの量 | 初めての店 |
| 出発 | 余裕30分のルート | 未確認の経路 |
| 移動中 | 争点メモを軽く見る | 新規の暗記 |
| 会場前 | 思考の型を1回読む | 長い会話 |

交通遅延を想定し、会場到着の30分前に駅を出る時刻をカレンダー登録しておくと安心です。

4本番中の立て直し手順

焦りが出たら、次の4ステップで思考負荷を下げます。

| 順番 | 作業 | 目安時間 |
| --- | --- | --- |
| 1 | 一度手を止める | 10秒 |
| 2 | 今の問番号を確認 | 5秒 |
| 3 | 保留ルールを読む | 10秒 |
| 4 | 次の易問へ進む | 即時 |
| 記録 | 焦りの問番号 | 終了後 |

固執が続く場合。

  • あらかじめ決めた切り替えフレーズ（例：「印を付けて前へ」）を紙に書き
  • 机上で見える位置に置いてください

53分野での迷いの切り分け

分野ごとに迷いの原因が違うため、演習後にタグを付けます。

| 分野 | 迷いの型 | 当日の一手 |
| --- | --- | --- |
| 法令・制度 | 条文の当てはめ | 争点3語→保留 |
| 契約・実務 | 長文の読み落とし | 主体・時点をメモ |
| 設備・税務 | 数値条件 | 印付きで後回し |
| 全体 | 順番の崩れ | 30分チェック |
| 記録 | 再発回数 | 翌日解き直し |

令和8年度は11月15日試験です。直前1週は新規範囲を増やさず、判断の型と睡眠を優先してください。

6よくある質問

当日に緊張で手が止まったらどうしますか？
10秒止めて問番号を確認し、保留ルールの行動文を読んでから次の易問へ進みます。その場で正解を追い続けるより、順番を戻す方が120分全体の得点を守りやすいです。演習で焦りが出た問番号を記録し、直前週に同じ手順で再現練習してください。
メンタル対策と時間配分の記事の違いは？
本記事は焦り・不安時の立て直しと判断の固定が中心です。試験当日の時間配分の記事は、到達問数・見直し10分など数値管理が中心です。先に時間配分で中間目標を決め、本記事で迷ったときの戻し順を足すと当日が安定しやすいです。
直前に新しい教材を読んでも大丈夫ですか？
直前1〜2週間は新規教材より、50問120分の通しと誤答の解き直しを優先した方が安全です。情報を増やすと不安が増幅し、当日の判断の型が崩れやすくなります。争点メモの見直しと睡眠を固定し、本番では演習で決めた保留ルールだけを使ってください。
