賃貸不動産経営管理士試験のマークシート・解答形式の確認と演習

「CBT」と聞いてパソコン試験を想像しがちですが、賃貸不動産経営管理士試験の学科試験は要項どおりマークシート式の四肢択一が中心です。令和8年度は50問・120分・3分野、試験日は2026年11月15日（日）13:00〜15:00、受験料12,000円（要項どおり）です。本記事では一般財団法人 賃貸不動産経営管理士試験センター要項を正本として、形式4項目、マークの練習、通し演習への反映を表で説明します。問題数・解答方式の変更は https://www.chintaikanrishi.jp/ の要項で必ず再確認してください。

この記事の要点

本記事を読むと、本番の解答形式と持ち込み禁止が分かり、マークシート操作と50問120分の通し演習を同じ条件で練習する手順が具体的に分かります。

  • 要項が正本
  • 学科はマークシート中心
  • 50問120分で通し練習
  • マークミスを記録
  • 45問は別枠で確認

1要項で確認する形式4項目

解答形式の正本は試験センター令和8年度受験要項です。他資格のCBT体験だけで準備すると、持ち物や解答手順がずれやすくなります。

| 項目 | 令和8年度の公表例（要項で再確認） | 演習への反映 |
| --- | --- | --- |
| 試験時間 | 13:00〜15:00（120分） | 通しは120分計測 |
| 問題数 | 50問（5問免除は45問） | 通しの問数を合わせる |
| 解答方式 | マークシート・四肢択一（要項） | 鉛筆マークの練習 |
| 出題分野 | 3分野 | 分野別→通しの順 |

申込前と試験6週前の2回、要項PDFで4項目を上書き確認してください。

2マークシートで起きやすいミス

知識があっても、マークミス・消し残し・解答欄の取り違えで失点することがあります。

| ミスの型 | 予防 | 演習での確認 |
| --- | --- | --- |
| 行ずれ | 5問ごとに番号を声に出す | 通し後に未解答を数える |
| 二重マーク | 消しゴムで完全消去 | 練習用紙で消し癖を固定 |
| 迷いの長時間 | 2分超は印だけ付ける | 超過問番号を記録 |
| 見直し省略 | 最後5分を予約 | 通しで見直し時間を計測 |

試験当日の持ち物の記事と併用し、HB鉛筆・消しゴム・受験票・身分証を前日までに揃えてください。

3本番と同条件の演習設計

形式練習は、問題の難易度より「問数・時間・マーク操作」を先に合わせます。

| 時期 | 演習 | 記録 |
| --- | --- | --- |
| 残り16週以上 | 分野別10〜20問＋マーク練習 | 分野別正答率 |
| 残り8〜15週 | 週末20問＋月1回通し50問 | 未解答数 |
| 残り7週以内 | 通し月2回 | マークミス数 |
| 直前2週 | 解き直し | 再発誤答のみ |

模試が画面解答のみの場合は、本番2か月前までにマークシート条件へ切り替えてください。過去問の回し方は過去問の効果的な使い方の記事で整理できます。

445問受験（5問免除）の確認

講習修了等により45問となる場合は、要項の該当章で問題数と合格基準を別途確認します。

| 確認 | 通常50問 | 45問受験 |
| --- | --- | --- |
| 問題数 | 50問 | 要項の記載 |
| 演習 | 50問通し | 45問通しに変更 |
| 時間 | 120分 | 要項どおり |
| 申込 | 区分の該当 | 証明書類の有無 |

  • 演習を50問のまま続けると
  • 本番のペース感がずれるため
  • 申込確定後は通し演習の問数も要項に合わせてください

5形式理解と他記事の使い分け

形式の数字（50問・120分・3分野）は試験形式の概要の記事で全体像を押さえ、本記事はマーク操作と通し演習への落とし込みが中心です。

| 記事 | 中心テーマ |
| --- | --- |
| 試験形式の概要 | 時間配分・分野の枠組み |
| 本記事 | マーク・通し演習の条件 |
| 持ち物 | 当日の持ち込み・禁止 |
| 過去問の使い方 | 誤答記録と復習 |

  • 直前週は新しい模試を増やさず
  • 要項で形式を1回確認したうえで
  • 誤答上位の解き直しに時間を使ってください

8よくある質問

賃貸不動産経営管理士試験はCBT（パソコン）ですか？
令和8年度要項では、学科試験はマークシート式の四肢択一・50問・120分・3分野と公表されています。他資格のCBT対策記事の手順をそのまま当てはめず、要項の「試験方法」「解答方法」を開いて確認してください。演習もマークシート（または同等のマーク練習）で行うと、本番の操作ミスを減らせます。
マークシートの練習はいつから始めればよいですか？
知識演習と並行して、残り12週前から週1回のマーク練習を入れることを推奨します。それ以前は分野別でも構いませんが、試験8週前からは50問120分の通しを月2回、必ず鉛筆マークで計測してください。直前2週は新規問題より解き直しとマーク確認に寄せてください。
画面の模試だけでも形式対策になりますか？
知識と時間感覚の訓練には有効ですが、マーク操作の練習にはなりません。本番2か月前までに、50問（または45問）・120分・マークシート条件の通し演習へ切り替えてください。試験形式の概要の記事で時間配分の目安を確認し、通し後は未解答数とマークミスを記録すると改善が速くなります。
