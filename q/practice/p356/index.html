必要経費に関する次の記述のうち、正しいものはどれか。

問題

必要経費に関する次の記述のうち、正しいものはどれか。

選択肢

  1. （1） 固定資産税や損害保険料などは、不動産所得の必要経費となり得る。
  2. （2） 固定資産税は、不動産所得の必要経費となる余地が全くない。
  3. （3） 修繕費は、どのような場合でも必要経費に算入できない。
  4. （4） 私的な旅行費用でも、賃貸経営と無関係に常に必要経費になる。

正答

正答は （1） です。

解説

正答は（1）です。

正解の理由

本問は、金銭管理・金銭管理・必要経費について、正しい記述を選ぶ問題です。選択肢1は「固定資産税や損害保険料などは、不動産所得の必要経費となり得る。」という内容で、論点の基本整理に合っています。金銭や費用の選択肢は、誰の財産か、預り金か、必要経費か、返還義務があるかを分けて考えます。基本解説としては、必要経費は、不動産収入を得るために直接必要で、家事費と区分できる費用が対象です。金銭管理では、入金・出金・預り金・未収金を区別し、委託者へ説明できる帳簿や証憑を残すことが基本です。賃料や敷金は似た場面で扱われますが、収益になるもの、預り金として返還可能性があるもの、必要経費になるものは性質が異なります。他の選択肢の確認です。選択肢2は「固定資産税は、不動産所得の必要経費となる余地が全くない。」という内容です。「常に」「当然に」「一切」などの断定が強い表現は、例外を無視していないかを確認します。選択肢3は「修繕費は、どのような場合でも必要経費に算入できない。」という内容です。金銭や費用の選択肢は、誰の財産か、預り金か、必要経費か、返還義務があるかを分けて考えます。選択肢4は「私的な旅行費用でも、賃貸経営と無関係に常に必要経費になる。」という内容です。「常に」「当然に」「一切」などの断定が強い表現は、例外を無視していないかを確認します。正しいものを選ぶ問題では、これらのように要件の一部を落としていたり、断定が強すぎたりする選択肢を消去します。

（1） 固定資産税や損害保険料などは、不動産所得の必要経費となり得る。
