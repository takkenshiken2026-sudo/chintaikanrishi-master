2020年 · 民法・借地借家法

賃貸不動産経営管理士試験 過去問 2020年 第24問（民法・借地借家法）

貸主が、借主の賃料不払を理由として建物賃貸借契約を解除する場合についての以下の記述の中で、誤っているものの組合せを選びなさい。ただし、それぞれの選択肢に記載のない事実及び特約はないものとする。

問題

貸主が、借主の賃料不払を理由として建物賃貸借契約を解除する場合についての以下の記述の中で、誤っているものの組合せを選びなさい。ただし、それぞれの選択肢に記載のない事実及び特約はないものとする。

  1. ア 賃料の支払を１か月でも滞納すれば貸主が催告を経ずに賃貸借契約を解除できるという特約を定めた場合、11月分までの賃料に滞納はなかったが、11月末日が支払期限である12月分の賃料が支払われなかったときは、12月１日に貸主が行った解除通知は有効となる。
  2. イ 借主に対して解除を通知した上で建物明渡請求訴訟を提起した貸主は、賃料の不払につき借主に故意過失があったことについては立証する必要はない、という内容である。
  3. ウ 賃料不払のため契約を解除すると口頭で伝えられた借主が、通知を書面で受け取っていないので解除は無効となると反論したが、このような反論は解除の効力に関係がない。
  4. エ 賃料が３か月間滞納されていることを理由に契約を解除するとの通知書を受け取った借主が、それまで一度も滞納賃料の催告を受けたことがないので解除は無効となると反論したが、このような反論は解除の効力に関係がない。

選択肢

  1. （1） ア・エ
  2. （2） イ・ウ
  3. （3） ウ・エ
  4. （4） ア・イ

正答

正答は （1） です。

解説

本問は「誤っているもの」を選ぶ問題です。（1）の記述が不適切なため、正答は（1）です。

正解の理由

（1）「ア・エ」は、設問の条件に照らして問題のある記述です。他の選択肢は単独では適切な内容が多いため、四肢を比較して不適切なものを選びます。

（1） ア・エ

他の選択肢

  • （2） イ・ウ

    （2）「イ・ウ」は正答にはなりません。 記述イ・ウは正しい記述のため、「誤っているものの組合せ」には当たりません。 誤っている記述ア・エが含まれていません。

  • （3） ウ・エ

    （3）「ウ・エ」は正答にはなりません。 記述ウは正しい記述のため、「誤っているものの組合せ」には当たりません。 誤っている記述アが含まれていません。

  • （4） ア・イ

    （4）「ア・イ」は正答にはなりません。 記述イは正しい記述のため、「誤っているものの組合せ」には当たりません。 誤っている記述エが含まれていません。

学習のヒント

借地借家・民法改正の問題は、権利関係の主体と効果の発生時期を一文で説明できるかが要点です。間違えた肢は「誰に・いつ・どの効果が及ぶか」で正答と対比し、関連用語から解き直してください。
