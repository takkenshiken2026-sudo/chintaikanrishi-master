2020年 · 賃料管理・督促

賃貸不動産経営管理士試験 過去問 2020年 第29問（賃料管理・督促）

建物明渡しの訴訟及び強制執行についての以下の記述の中で、正しいものの組合せを選びなさい。

問題

建物明渡しの訴訟及び強制執行についての以下の記述の中で、正しいものの組合せを選びなさい。

  1. ア 公正証書により賃貸借契約を締結したとしても、公正証書に基づき建物明渡しの強制執行を行うことはできない、という内容である。
  2. イ 訴額が60万円以下の場合は、少額訴訟を提起することにより建物の明渡しを求めることができる、という内容である。
  3. ウ 即決和解（起訴前の和解）が成立したとしても、和解調書に基づき建物明渡しの強制執行を行うことはできない、という内容である。
  4. エ 裁判上の和解が成立した場合、和解調書に基づき建物明渡しの強制執行を行うことができる、という内容である。

選択肢

  1. （1） ア・イ
  2. （2） イ・ウ
  3. （3） ア・エ
  4. （4） ウ・エ

正答

正答は （3） です。

解説

本問は「正しいもの」を選ぶ問題です。（3）の記述が最も正確なため、正答は（3）です。

正解の理由

（3）「ア・エ」は、制度・実務の整理に沿った正しい記述です。他の選択肢は要件・主体・数字・期限などの点でずれている部分があります。

（3） ア・エ

他の選択肢

  • （1） ア・イ

    （1）「ア・イ」は正答にはなりません。 記述アは正しい記述のため、「誤っているものの組合せ」には当たりません。 誤っている記述ウが含まれていません。

  • （2） イ・ウ

    この肢は「イ・ウ」と述べていますが、賃料管理・督促の基準では正しい記述ではありません。

    正答（3）「ア・エ」は、制度・手続・学習法のいずれかの観点で適切な内容です。

    正答の論点と照らすと、この肢は「イ・ウ」という断定のどこかが設問の前提と矛盾します。主語・客体・数字・期限・「毎年／常に／不要」などの限定語をチェックしてください。

  • （4） ウ・エ

    （4）「ウ・エ」は正答にはなりません。 記述エは正しい記述のため、「誤っているものの組合せ」には当たりません。 誤っている記述イが含まれていません。

学習のヒント

賃料・督促は手続の順序と法的効果（催告・解除等）の対応が重要です。タイムラインで整理し、誤答肢がどの段階・要件を誤っているかを確認してください。
