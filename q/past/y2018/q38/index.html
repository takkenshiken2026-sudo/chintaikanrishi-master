2018年 第38問（管理実務）

賃貸不動産経営管理士「倫理憲章」についての以下の記述の中で、正しいものの組合せを選びなさい。

問題

賃貸不動産経営管理士「倫理憲章」についての以下の記述の中で、正しいものの組合せを選びなさい。

  1. ア 秘密を守る義務とは、職務上知り得た秘密を正当な理由なく他に漏らしてはならないことであり、賃貸不動産経営管理士の職務に携わっている間、守らなければならない、という内容である。
  2. イ 賃貸不動産経営管理士は、自らの能力や知識を超える業務を引き受けてはならない、という内容である。
  3. ウ 賃貸不動産経営管理士は、常に依頼者の立場で職務を行い、万一紛争等が生じた場合には、誠意をもって、その円満解決に努力する必要がある。
  4. エ 賃貸不動産経営管理士は、公共的使命を常に自覚し、公正な業務を通して、公共の福祉に貢献する必要がある。

選択肢

  1. （1） ア・イ
  2. （2） ア・ウ
  3. （3） イ・エ
  4. （4） ウ・エ

正答

正答は （3） です。

解説

正答は（3）です。

正解の理由

本問は、管理実務・倫理憲章について、正しい記述の組合せを選ぶ問題です。選択肢3（イ、エ）が正解です。各記述の判定は、記述アは不適切、記述イは適切、記述ウは不適切、記述エは適切です。組合せ問題では、選択肢の文字列に引っ張られず、各記述の正誤を先に確定させることが大切です。

（3） イ・エ

他の選択肢

  • （1） ア・イ 問題文の趣旨・試験制度の基本に照らすと誤りです。
  • （2） ア・ウ 問題文の趣旨・試験制度の基本に照らすと誤りです。
  • （4） ウ・エ 問題文の趣旨・試験制度の基本に照らすと誤りです。
